# 🚀 دليل تشغيل واستعراض موقع البورتفوليو الحديث (Mekhael Nabil Portfolio 2.0)

تمت ترقية وتحديث موقع البورتفوليو بالكامل ليصبح موقعاً تفاعلياً متعدد الصفحات مبنياً بأحدث المعايير البرمجية:
- **React 19 & TypeScript**
- **Tailwind CSS v4**
- **Vite & Modern Bundler**
- **Framer Motion & Canvas Confetti**

---

## 🛠️ أوامر التشغيل السريعة:

### 1. تشغيل بيئة التطوير المباشرة (Dev Server):
```bash
npm run dev
```
سيفتح الموقع على الرابط: `http://localhost:3000` مع خاصية التحديث الفوري (Hot Module Replacement - HMR).

### 2. بناء المشروع لبيئة الإنتاج (Production Build):
```bash
npm run build
```
يقوم ببناء ملفات الإنتاج فائقة السرعة والصغيرة حجماً داخل مجلد `dist`.

### 3. معاينة نسخة الإنتاج (Production Preview):
```bash
npm run preview
```
يقوم بتشغيل سيرفر سريع ومحلي للمعاينة على: `http://localhost:4173`.

## 🌟 الميزات والمكونات المنجزة:
1. **هيكل متعدد الصفحات (6 صفحات أساسية):**
   - **الرئيسية (Home):** نبذة بصرية ديناميكية، إحصائيات سريعة، وأبرز المشاريع المميزة.
   - **معرض المشاريع (Projects):** فلترة ذكية بالأقسام (معارض السيارات، السفاري، الطيران، لوحات التحكم)، روابط حية (Live Demos)، مستودعات GitHub، ونوافذ تفاصيل تقنية منبثقة.
   - **عني (About):** قصة ميخائيل نبيل، الشغف بالبرمجة، والقيم والمعايير والمسار الزمني للتطور.
   - **المهارات والتقنيات (Skills):** استعراض مهارات React, TypeScript, Modern CSS, HTML5 بنسب إتقان وشاشات تقدمية.
   - **التقييمات والآراء (Reviews):** نظام تقييم حي تفاعلي بالنجوم مع احتفالية تفاعلية (Confetti) وإحصائيات فورية للزوار.
   - **التواصل (Contact):** قنوات التواصل المباشرة، وحسابات السوشيال ميديا ونموذج اتصال سريع مع التحقق من صحة المدخلات.

2. **روبوت التفاعل الذكي في الهيدر (Mouse-Tracking Interactive Robot):**
   - كائن SVG ثلاثي الأبعاد مدمج في الهيدر.
   - تتبع فوري وبدقة متناهية لحركة الماوس في كامل الشاشة (تحريك بؤبؤ العينين ودوران الرأس ببعد 3D).
   - وميض طبيعي ومستشعر تفاعلي عند النقر يلوح باليد ويرحب بالزائر.

3. **أنيميشن وكشف دائري متطور (Circular Reveal & Scroll Animations):**
   - تأثير كشف دائري `clip-path: circle()` يتسع بانسيابية مع التمرير.
   - تأثيرات طفو `floating` وانتقالات سلسة `Page Transitions` بين الصفحات دون إعادة تحميل الصفحة بالكامل.

4. **الوضع الليلي والنهاري (Dark/Light Mode Toggle):**
   - حفظ التفضيل تلقائياً في `localStorage` مع دعم التبديل بين اللغتين (العربية والإنجليزية).

5. **شاشات التحميل والسكيليتون (Skeleton Loaders):**
   - تدرج لوني انسيابي نابض أثناء تحميل الصور والمحتوى لحماية تجربة المستخدم من أي انقطاع.
